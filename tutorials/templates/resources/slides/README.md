# Slide Templates

These slide templates are for teaching documents that need more polish than Markdown diagrams.

They are based on the Agentic Engineer course slide style.

Use them for:

- mental models
- workflow diagrams
- before and after comparisons
- step-by-step loops
- short code or prompt examples
- final takeaway slides

Do not use slides for every lesson by default.

Use them when the visual makes the idea clearer.

## Files

- [teaching-deck.html](./teaching-deck.html) is a standalone browser deck.

## How To Use

1. Copy `teaching-deck.html` into `tutorials/<slug>/resources/slides/`.

2. Rename it to match the lesson.

3. Replace the title slide and section labels.

4. Keep one idea per slide.

5. Verify it in a browser at desktop and mobile widths.

## Template Patterns

The deck includes these common teaching slides:

- title slide
- plain idea slide
- pipeline diagram
- card comparison
- loop diagram
- code or prompt slide
- takeaway slide
