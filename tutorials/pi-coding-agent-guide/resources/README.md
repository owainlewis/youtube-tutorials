# Optional Pi Examples

The complete teaching path is in [`../LESSON.md`](../LESSON.md). These files are
optional examples to inspect or copy after the basic workflow is working.

| Resource | Use it when |
| --- | --- |
| [Provider and cost notes](./00-pricing/) | You need to understand what Pi's usage display does and does not measure. |
| [Command reference](./01-getting-started/) | You want a short reminder of common interactive commands. |
| [Configuration examples](./02-configuration/) | You need an appended system prompt, settings, or a custom local provider. |
| [Extension examples](./03-extensions/) | You want to add runtime behaviour with TypeScript. |
| [Skill example](./04-skills/) | You want reusable task instructions. |
| [Migration notes](./05-claude-code-migration/) | You are comparing Pi with Claude Code. |
| [Custom provider notes](./06-multi-provider/) | A built-in provider does not cover your endpoint. |
| [Advanced modes](./07-advanced/) | You need print, JSON, RPC, or SDK integration. |
| [Project instructions](./pi/AGENTS.md) | You need a starting point for an `AGENTS.md` file. |

The sample extensions execute with the current user's permissions. Review them
before loading them into Pi.
