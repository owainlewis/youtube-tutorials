# Pi Command Reference

Installation and provider configuration live in the complete
[`LESSON.md`](../../LESSON.md). This page is only a quick command reminder.

| Command | What it does |
| --- | --- |
| `/login` and `/logout` | Manage provider credentials. |
| `/model` | Select a provider and model. |
| `/scoped-models` | Control which models appear while cycling. |
| `/session` | Show session metadata and reported usage. |
| `/tree` | Navigate branches in the current session. |
| `/compact` | Summarise older context. |
| `/new` | Start a new session. |
| `/reload` | Reload instructions and custom resources. |
| `/hotkeys` | Show shortcuts for the installed release. |

Run `pi --help` for CLI flags and `/hotkeys` for keyboard shortcuts. Those two
commands are more reliable than a copied list when Pi changes.
