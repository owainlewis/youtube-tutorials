# Core Fundamentals

This is the supporting material for the video: Core Fundamentals.

Learn one language deeply. Python. Not because you'll write production code by hand forever, but because you need to read and review what AI generates.

## What to Learn

### Python Basics (Weeks 1-2)
- [ ] Variables and data types
- [ ] Functions and parameters
- [ ] Control flow (if/else, loops)
- [ ] Lists, dictionaries, sets, tuples
- [ ] String manipulation
- [ ] File I/O (reading and writing files)

### Intermediate Python (Weeks 3-4)
- [ ] Classes and objects
- [ ] Error handling (try/except)
- [ ] Modules and imports
- [ ] List comprehensions
- [ ] Working with JSON
- [ ] HTTP requests (the `requests` library)

### Code Fluency (Weeks 5-8)
- [ ] Read code you didn't write (open source repos on GitHub)
- [ ] Trace execution mentally (what happens line by line?)
- [ ] Spot common bugs (off-by-one, None checks, wrong types)
- [ ] Understand error messages and stack traces
- [ ] Write small programs from scratch without AI
