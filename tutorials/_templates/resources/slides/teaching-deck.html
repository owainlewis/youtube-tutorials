Tutorial Title

Teaching Deck Template

Use slides when the visual model makes the lesson easier to remember.

The plain idea

Start With The Job The System Must Do

Do not start with tools.

Name the problem, show the weak default, then give the viewer the useful model.

Pipeline pattern

Use A Pipeline For Workflow Lessons

INPUT-> CONTEXT-> ACTION-> EVIDENCE-> NEXT STEP

This works well for agent loops, review flows, deployment flows, and memory systems.

Comparison pattern

Use Cards To Separate Concepts

01

What It Is

The plain definition.

02

Why It Matters

The problem it solves.

03

Where It Breaks

The tradeoff or risk.

04

What To Do

The practical next move.

Before and after

Use A Split For Weak Default Versus Better Model

Weak Default

  • Starts with tools.
  • Stores too much context.
  • Does not define ownership.

Better Model

  • Starts with the job.
  • Loads only useful context.
  • Defines rules for updates.

Loop pattern

Use A Loop For Recurring Agent Systems

Load

Bring in the useful context.

->

Act

Call the model or run the workflow.

^

Save

Store only what matters.

<-

Code or prompt

Use Code Blocks For The Exact Thing To Copy

Before continuing, audit the session.

What context did you inspect?
What did you assume?
What tools did you use?
What evidence do we have?
What should we verify next?

Takeaway

Good slides make the lesson easier to remember.

Keep the lesson as the source of truth.
