# OpenAI Codex For Developers

A practical guide to using OpenAI Codex as a professional developer. Covers the CLI, desktop app, Linear workflow, automations, and the system layer that makes it all work well.

## Start Here

- Read the lesson: [LESSON.md](./LESSON.md)
- Browse chapter folders: [01-setup](./01-setup/), [02-plans-and-specs](./02-plans-and-specs/), [03-review](./03-review/), [04-skills](./04-skills/), [05-plugins](./05-plugins/), [06-automation](./06-automation/)
- Use supporting resources: [resources](./resources/)

## What's Inside

- `LESSON.md` - the main teaching document.
- Chapter folders - deeper steps or course-style sections that support the main lesson.
- Resource folders - prompts, examples, commands, docs, slides, or copyable files.
- Supporting files - [`codex-permissions-guide.md`](./codex-permissions-guide.md), [`config.toml.example`](./config.toml.example).
