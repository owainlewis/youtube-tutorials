# PostgreSQL for RAG

Build a production RAG chatbot on PostgreSQL with pgvector - vector search, full-text search, and hybrid search using a database you already know and trust.

## Start Here

- Read the lesson: [lesson.md](./lesson.md)
- Explore code samples: [src](./src/), [sql](./sql/)
- Use supporting resources: [docs](./docs/)

- `lesson.md` - the main teaching document.
- Code folders - runnable examples, demo apps, SQL, Terraform, or sample tools.
- Resource folders - prompts, examples, commands, docs, slides, or copyable files.
- Supporting files - [`docker-compose.yml`](./docker-compose.yml), [`pyproject.toml`](./pyproject.toml), [`start.sh`](./start.sh).
